The strike, drawn by hand

A CSS bar is the default nobody chose, and it fights a page written as a signed note. These are inline SVG paths — a different path on every line, because a real hand does not draw the same stroke three times, and identical strikes are what made the first version read as software.

Each strike overshoots the word at both ends, the way a pen does. Stroke width is pinned with vector-effect: non-scaling-stroke, so stretching the path across a long word like Invoice chaser. does not thin the line.

1. Jagged, coral Recommended

Reads as a pen crossing items off a list — which is exactly the feeling. Coral is the only warm thing on the card, so the eye goes to the strike, then to the one word that is not struck.
