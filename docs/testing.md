## Measuring duplication

`bun run dupes` runs jscpd (pinned in the root `package.json`) with `.jscpd.json` and prints one table: production and test rows, and for each format the clones and duplicated lines, plus totals. It also writes the same numbers to `.jscpd-report/dupes.json` (git-ignored), by kind and format, for a later comparison against a committed baseline. Measure with this command and no other, so every number comes from the same scope (#2743).

The scope is `app/src` and `api/`, in `typescript`, `svelte`, `css` and `go`, at 50 tokens minimum. It leaves out `api/internal/pdffont/fonts/` (third-party license texts), `api/db/migrations/` (applied migrations are never edited, so their clones cannot be removed) and `app/src/lib/components/atoms/Icon/generated/` (written by `bun run sync-icons`). The Svelte column counts markup only; the script block of a `.svelte` file counts under `typescript`, and its `<style>` under `css`.

A clone counts as test when either side is a test file: `*_test.go`, `*.spec.ts`, `*.test.ts`, a file under an `e2e/`, `testdata/`, `testing/`, `fixtures/`, `harness/` or `vitest-examples/` directory, a fixture or test helper (`*.fixture.ts`, `*Fixture.ts`, `*.testing.ts`, `test[A-Z]*` and `Test[A-Z]*` files, `vitest.*.setup.ts`), a Go fake (`fake.go`, `*_fake.go`), or a file in the Go test-helper packages `testdb`, `authntest`, `apierrtest` and `reqtest`. Every other clone is production. The rules are `isTestFile` in `scripts/dupes.ts`.
